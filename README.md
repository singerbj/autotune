# TunedUp

A Windows desktop app, built in Rust with Tauri 2, that pitch-corrects your
microphone in real time. You hear the tuned voice in your headphones at
about 12–20 ms on a wired USB headset, and Discord (or any app) gets it
through VB-Cable.

- **Tuning:** key + scale (chromatic, major, natural minor, custom notes),
  retune speed 0–200 ms, humanize, voice-range presets that set the DSP
  latency (Low 14 ms / Mid 10 ms / High 7 ms), dry/wet mix, noise gate,
  click-free bypass from the UI, tray or a global hotkey, and named presets.
- **Audio:** WASAPI exclusive → IAudioClient3 low-latency shared → shared
  fallback chain (ASIO tier behind a feature), shared-mode headphone monitor,
  adaptive resampling into VB-Cable, recovery from unplug/replug in < 2 s.
- **Setup:** first-run wizard (devices, VB-Cable, conflicts, sidetone and
  Bluetooth warnings, Discord checklist with live detection, latency test),
  optional "Use for all apps" that makes CABLE Output the default mic and is
  always restored — even after a crash.
- **Diagnostics:** live latency estimate, acoustic loopback measurement,
  meters, backend tier, xruns, callback p99/max, "Copy diagnostics".
- **Shell:** tray, close-to-tray, single instance, launch at login, versioned
  settings, signed auto-updates from GitHub Releases.

The design lives in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), the
requirements in [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md), deviations in
[`docs/decisions/`](docs/decisions/), and requirement → test mapping in
[`docs/TRACEABILITY.md`](docs/TRACEABILITY.md).

## Install

1. Download `TunedUp_<version>_x64-setup.exe` from the
   [latest release](https://github.com/singerbj/autotune/releases/latest).
2. Run it and accept the single UAC prompt. If VB-Cable is not installed yet
   the installer installs it silently and asks for one reboot; after the
   reboot the app opens in the setup wizard.
3. Follow the wizard. In Discord set **Input Device** to *Default* or
   *CABLE Output (VB-Audio Virtual Cable)* and turn off Noise Suppression,
   Echo Cancellation and Automatic Gain Control.

Silent install for managed machines: `TunedUp_<version>_x64-setup.exe /S`
(set `TUNEDUP_SKIP_VBCABLE=1` to skip the driver).

Requirements: Windows 10 22H2 or Windows 11, x64. WebView2 is installed
automatically if missing.

## Updates

The app checks GitHub Releases shortly after launch and every six hours,
downloads new versions in the background, verifies their signature, and
shows **Update ready**. Click it (or use the tray, or just quit) to install;
your settings are kept. Turn automatic checks off in *Settings*. Details:
[`docs/RELEASING.md`](docs/RELEASING.md).

## Uninstall

*Settings → Apps → TunedUp → Uninstall* (or run `uninstall.exe`). The
uninstaller:

1. restores your previous default microphone if "Use for all apps" changed it;
2. removes the app, shortcuts and the launch-at-login entry, and optionally
   your settings (`%APPDATA%\io.github.singerbj.tunedup`) and logs;
3. offers to remove VB-Cable — only if TunedUp installed it.

Silent: `"C:\Program Files\TunedUp\uninstall.exe" /S` (keeps VB-Cable).

## Repository layout

```text
crates/
  tuner-dsp/     pitch detection (MPM), scale snap, PSOLA — pure Rust, no OS deps
  tuner-audio/   AudioBackend trait, WASAPI (+ASIO) backends, rings, resampler, mock backend
  tuner-engine/  capture/monitor/cable threads, live params, meters, latency test, supervisor
  tuner-win/     IPolicyConfig + crash-safe restore, device notifications, sessions, setup check
  tuner-cli/     offline WAV harness, pitch tracks, golden files
src-tauri/       Tauri 2 app: typed commands/events, tray, hotkey, updater, config
ui/              React + TypeScript + Vite frontend (bindings generated by tauri-specta)
installer/       NSIS hooks and the VB-Cable install/uninstall script
scripts/         release version bump, CI gates
docs/            requirements, architecture, ADRs, releasing, traceability
```

## Development

```sh
npm install        # UI deps + git hooks
npm run dev        # run the app (Windows for real audio; mock backend elsewhere)
npm run check      # everything CI lints
npm test           # Vitest + cargo test
```

Offline DSP without any audio hardware:

```sh
cargo run -p tuner-cli -- gen --kind vocal -o vocal.wav
cargo run -p tuner-cli -- tune -i vocal.wav -o tuned.wav --key C --scale major --retune-ms 5
cargo run -p tuner-cli -- track -i tuned.wav
```

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for hooks, PR checks and conventions.

## CI/CD

- **CI** (`.github/workflows/ci.yml`, every PR and push to `main`): PR-title
  lint, frontend checks and build, Rust fmt/clippy/tests on
  `windows-latest`, portable crates on Linux, ASIO feature build, NFR-03
  benchmark gate, one-hour no-alloc soak, cargo-deny + npm license audit,
  Pester tests for the installer script, and an unsigned installer build with
  an install/uninstall smoke test. One aggregate **CI success** check.
- **Release** (`.github/workflows/release.yml`): run it with a version (or push
  `vX.Y.Z`); it bumps versions, tags, builds and signs the installer, and
  publishes a GitHub Release with `latest.json` for the updater.
- **Dependabot** keeps Cargo, npm and Actions dependencies current.
